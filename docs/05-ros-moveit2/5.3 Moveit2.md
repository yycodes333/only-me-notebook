# 5.3 Moveit2





#### 1. 安装Moveit2

二进制安装

```shell
sudo apt install ros-$ROS_DISTRO-moveit*

----------------------   或者：推荐下面安装方式 --------------------

sudo apt update

# 安装 MoveIt 2 核心及周边所有组件
sudo apt install -y \
  ros-$ROS_DISTRO-moveit \
  ros-$ROS_DISTRO-moveit-planners-ompl \
  ros-$ROS_DISTRO-moveit-ros-visualization \
  ros-$ROS_DISTRO-moveit-setup-assistant \
  ros-$ROS_DISTRO-moveit-ros2-control \
  ros-$ROS_DISTRO-moveit-servo \
  ros-$ROS_DISTRO-moveit-visual-tools \
  ros-$ROS_DISTRO-rviz-visual-tools \
  ros-$ROS_DISTRO-trac-ik-kinematics-plugin
```

若安装太慢可添加代理。可参考以下方法：

```shell
----------------#临时配置代理---------------------------
export http_proxy=http://127.0.0.1:7897(自己端口号)
export https_proxy=http://127.0.0.1:7897(自己端口号)
----------------#永久配置代理---------------------------
nano ~/.bashrc
# 代理快捷开关 (端口7897)
alias proxy="export http_proxy=http://127.0.0.1:7897; export https_proxy=http://127.0.0.1:7897; echo '终端代理已开启 ✈️'"
alias unproxy="unset http_proxy https_proxy; echo '终端代理已关闭 🛑'"
#让配置立刻生效：
source ~/.bashrc
----------------#后续使用-------------------------------
proxy#开启代理
unproxy#关闭代理

#验证代理是否成功
#(如果输出里有 HTTP/2 200 或类似成功的信息，说明终端代理设置成功)
curl -I https://www.google.com
"""
sudo：申请管理员权限
-E：带着你刚才设置的 7897 代理环境变量一起进入管理员模式（最关键的一步）
apt：系统包管理器
install：安装指令
ros-humble-moveit*：把所有叫这个名字开头的 MoveIt 包都装上

"""
sudo -E apt update
sudo -E apt install xx
```

安装完 MoveIt2 之后，需要安装一些依赖

```shell
# 安装底层控制和轨迹执行所需的所有控制器
sudo apt install -y \
  ros-$ROS_DISTRO-ros2-control \
  ros-$ROS_DISTRO-ros2-controllers \
  ros-$ROS_DISTRO-joint-state-broadcaster \
  ros-$ROS_DISTRO-joint-trajectory-controller \
  ros-$ROS_DISTRO-gripper-controllers \
  ros-$ROS_DISTRO-trajectory-msgs
```



若系统语言区域设置不为英文区域，须设置

```shell
echo "export LC_NUMERIC=en_US.UTF-8" >> ~/.bashrc
source ~/.bashrc
```
