# 4.4 速度和静力

此前在4.3 运动学节讨论的正运动学与逆运动学，主要研究机械臂的**位姿关系**。正运动学根据关节变量 $q$ 计算末端位姿 $X$：

```math
X = f(q)
```

逆运动学则根据期望末端位姿，求取对应的关节变量：

```math
q = f^{-1}(X)
```

这些方法描述了机械臂“处于什么位置和姿态”，属于有限运动层面的问题。然而在机械臂实际运行与控制过程中，仅知道起点和终点并不足够，还需要进一步回答：

- 各关节以一定速度运动时，末端将以怎样的速度运动？
- 为使末端沿指定方向运动，各关节应分别以多大速度运动？
- 机械臂在某一构型下，是否会丧失部分运动能力？
- 当末端受到外力时，各关节需要承受多大的力或力矩？

因此，需要在某一瞬时构型附近研究关节变量微小变化与末端运动之间的关系，这便是机械臂的**微分运动学**。

对正运动学关系进行微分，可得：

```math
\dot{X} = J(q)\dot{q} 
```

其中：

- $\dot q$ 为关节空间速度；
- $\dot X$ 为末端在操作空间中的速度；
- $J(q)$ 为机械臂的雅可比矩阵。

雅可比矩阵建立了关节空间与操作空间之间的局部线性映射。其第 i列表示仅第 i个关节以单位速度运动时，对末端线速度和角速度产生的贡献。通过雅可比矩阵，可以完成末端速度计算、关节速度求解、奇异性分析以及微分运动控制。

除速度映射外，雅可比矩阵还建立了机械臂两侧力之间的传递关系。根据虚功原理，末端广义力与关节力矩满足：

```math
\tau = J^T(q)F
```

其中：

- F为作用于末端的力和力矩组成的六维力旋量；
- $\tau$ 为对应的关节驱动力或驱动力矩。

由此可见，速度关系与静力关系是同一几何映射的两个方面：

```math
\dot{X} = J(q)\dot{q}, \quad \tau = J^T(q)F
```

​	本节将围绕雅可比矩阵展开，首先介绍末端线速度与角速度的表示方法，并建立关节速度到末端速度的映射；随后讨论雅可比矩阵的构造、坐标变换及奇异性；最后利用虚功原理分析末端力与关节力矩之间的静力传递关系。

## 4.4.1  时变位姿的符号表示

### 1. 位置矢量的微分

速度以及加速度是需要研究的基本问题，可用下面符号表示某个矢量的微分：

```math
\begin{equation*}
{}^{B}V_Q = \frac{d}{dt}{}^{B}Q = \lim_{\Delta t \to 0} \frac{{}^{B}Q(t+\Delta t) - {}^{B}Q(t)}{\Delta t}
\tag{1}
\end{equation*}
```

**位置矢量的速度**可以看成是用位置矢量描述的空间一点的**==线速度==**。

由式 (1) 可以看出，可以通过计算Q相对于坐标系{B}的微分进行描述。例如，如果相对于坐标系{B}，Q不随时间变化，那么速度就为零，尽管在其他一些坐标系中Q是变化的。因此，重要的是**必须说明一个矢量**是**==相对于哪个坐标系求微分==**。

像其他矢量一样，速度矢量能在任意坐标系中描述，其参考坐标系可以用左上标注明。因此，如果在坐标系{A}中表示式 (1) 的速度矢量，可以写为

```math
\begin{equation}
{}^{A}\left( {}^{B}V_Q \right) = \frac{{}^{A}d}{dt} {}^{B}Q
\end{equation}
```

可以看出，在通常的情况下，速度矢量都是与空间的某点相关的，而描述此点速度的大小取决于两个坐标系：一个是进行微分运算的坐标系即**==相对哪个坐标系求导的坐标==系**，另一个是描述这个速度矢量的坐标系即==**相对于哪个坐标系表达**==。

在式 (1) 中，速度是用微分坐标系描述的，因此这个结果用左上标B注明。但是，为简单起见，当两个上标相同时，不需要给出外层上标，即可以写为

```math
\begin{equation}
{}^{B}\left( {}^{B}V_Q \right) = {}^{B}V_Q
\end{equation}
```

> 此处，由于相对于{B}坐标系微分，而此处又是在{B}坐标系表达，那么在外层的在{B}看的这个表达可以省略。

最后，由于进行参考坐标系变换的旋转矩阵已可清楚地表示这个关系，因此总是省略掉外部左上标，可以写为

```math
\begin{equation}
{}^{A}\left( {}^{B}V_Q \right) ={}_B^A R {}^B \left( {}^B V_Q \right)  = {}_B^{A}R \, {}^{B}V_Q
\tag{2}
\end{equation}

```

通常按照式（2）右边的形式给出速度的表达式，因此描述速度的符号总是代表**微分坐标系中的速度**，而没有外部左上标。

经常讨论的是一个坐标系原点相对于某个常见的世界参考坐标系的速度，而不考虑相对于任意坐标系中一般点的速度。对于这种特殊情况，定义一个缩写符号

```math
\begin{equation}
v_C = {}^{U}V_{CORG}
\end{equation}
```

式中的点为坐标系{C}的原点，参考坐标系为{U}。例如，用符号$v_C$表示坐标系{C}**原点的速度**；${}^A v_C$是坐标系{C}的原点在坐标系{A}中表示的速度（尽管微分是相对于坐标系{U}进行的）

```math
\begin{equation}
{}^A v_C = {}_U^{A}R \ · v_C 
\end{equation}
```

现在介绍角速度矢量，用符号Ω表示。线速度描述了点的一种属性，角速度则描述了刚体的一种属性。坐标系总是固连在被描述的刚体上，所以可以用角速度来描述坐标系的旋转。


```math
\begin{equation}
{}^A \omega_C = {}_C^{A}R \ · \omega_C 
\end{equation}
```

### 2. 角速度

仍然讨论与线速度相同的对象。坐标系 {A\} 与坐标系 {B}固连在同一刚体上，旋转矩阵 ${}^{A}_{B}R$ 描述坐标系{B} 相对于坐标系 {A} 的姿态。

与线速度不同，刚体上不同点的线速度通常不同，但整个刚体具有相同的角速度。

> 严格来说，角速度属于刚体或坐标系，而不是刚体上的某个点。因此不存在“\(A\) 点角速度”和“\(B\) 点角速度不同”的情况。

#### 1. 定义

坐标系{B} 的单位基向量分别为

```math
\hat{i}, \quad \hat{j}, \quad \hat{k}.
```

当坐标系{B} 相对于坐标系{A} 旋转时，这些单位基向量的方向会随时间变化。

设坐标系 {B} 相对于坐标系{A} 的角速度为$^A\omega_B$，则旋转坐标系中任意单位基向量的导数均满足

```math
\frac{\mathrm{d}\hat{i}}{\mathrm{d}t} = {}^A\omega_B \times \hat{i}, \\
\frac{\mathrm{d}\hat{j}}{\mathrm{d}t} = {}^A\omega_B \times \hat{j}, \\
\frac{\mathrm{d}\hat{k}}{\mathrm{d}t} = {}^A\omega_B \times \hat{k}.
```

这说明角速度描述了坐标系各坐标轴方向的变化速度。

> 该结论在线速度时候已经证明过

#### 2. 性质

同一个角速度向量可以分别使用坐标系 {A}和坐标系{B} 表示：

```math
^A\omega =
\begin{bmatrix}
^A\omega_x \\
^A\omega_y \\
^A\omega_z
\end{bmatrix},
\quad
^B\omega =
\begin{bmatrix}
^B\omega_x \\
^B\omega_y \\
^B\omega_z
\end{bmatrix}.
```

两种坐标表示之间通过旋转矩阵转换：

```math
\boxed{
^A\omega = {}_B^A R \, ^B\omega
}
```

如果坐标系{B}  相对于坐标系{A} 旋转，坐标系 {C}  又相对于坐标系{B}  旋转，则坐标系 {C}  相对于坐标系{A}  的角速度为

```math
\boxed{^A\omega_C = {}^A\omega_B + {}_B^A R{}^B\omega_{C}}
```

> 与线速度叠加公式相比，角速度叠加中不存在由平移位置产生的叉乘项。

#### 3. 旋转矩阵计算角速度

在第二节数学基础中，我们学习过旋转矩阵并且证明了旋转矩阵是一个正交矩阵，那么有

```math
RR^T = I_n
```

式中，$I_n$ 是 $n×n$ 单位阵。另外，我们关心的是 n=3, R 为特征正交矩阵，即旋转矩阵的情况。对上式对时间求导得

```math
\dot{R}R^T + R\dot{R}^T = 0_n
```

式中 $0_n$ 为 n×n 的零矩阵。上述方程又可以写为

```math
\dot{R}R^T + (\dot{R}R^T)^T = 0_n
```

令$S=\dot{R}R^T$，代入方程则

```math
S + S^T = 0_n
```

则说明S 为反对称矩阵

因此正交矩阵的微分与反对称矩阵之间存在如下特性，可写为

```math
\dot{R}R^{-1} =S
```



假定固定矢量 ${}^B P$ 相对于坐标系{B}是不变的，在另一个坐标系{A}中的描述为

```math
{}^A P = {}_B^A R \, {}^B P
```

如果坐标系{B}是旋转的（ $\dot{{}_B^A R}$ 的微分非零），${}^AP$ 也是变化的，即使 ${}^BP$为常数，即

```math
{}^A \dot{P} = {}_B^A \dot{R} \, {}^B P
```

或用速度符号写为

```math
{}^A V_P = {}_B^A \dot{R} \, {}^B P
```

在式 上式 中代入${}^B P$  的表达式，得

```math
{}^A V_P = {}_B^A \dot{R} \, {}_B^A R^{-1} \, {}^A P = {}^A_B S	\,{}^AP
```

式中用 S 的上下标表明它是与旋转矩阵 ${}_B^A R$相关的反对称矩阵，那么S就可以如下矩阵

```math
S =
\begin{bmatrix}
0 & s_{12} & s_{13} \\
s_{21} & 0 & s_{23} \\
s_{31} & s_{32} & 0
\end{bmatrix}
```

对于角速度我们有

```math
\omega = \begin{bmatrix}
\omega_x \\
\omega_y \\
\omega_z
\end{bmatrix}
```

任意向量有

```math
p = \begin{bmatrix}
p_x \\
p_y \\
p_z
\end{bmatrix}
```

角速度与位置向量的叉乘为：

```math
\omega \times p = \begin{bmatrix}
\omega_y p_z - \omega_z p_y \\
\omega_z p_x - \omega_x p_z \\
\omega_x p_y - \omega_y p_x
\end{bmatrix}
```

将其写成矩阵乘法：

```math
\omega \times p =
\begin{bmatrix}
0 & -\omega_z & \omega_y \\
\omega_z & 0 & -\omega_x \\
-\omega_y & \omega_x & 0
\end{bmatrix}
\begin{bmatrix}
p_x \\
p_y \\
p_z
\end{bmatrix}
```



定义叉乘定义如下：

```math
[\omega]_\times =
\begin{bmatrix}
0 & -\omega_z & \omega_y \\
\omega_z & 0 & -\omega_x \\
-\omega_y & \omega_x & 0
\end{bmatrix}
```



满足

```math
[\omega]_\times p = \omega \times p
```

而我们之前发现得S 形式于叉乘矩阵一致，因此叉乘矩阵一定是一个反对称矩阵，若S矩阵每个元素与叉乘矩阵依次对应即

```math
S =
\begin{bmatrix}
0 & s_{12} & s_{13} \\
s_{21} & 0 & s_{23} \\
s_{31} & s_{32} & 0
\end{bmatrix}
=\begin{bmatrix}
0 & -\omega_z & \omega_y \\
\omega_z & 0 & -\omega_x \\
-\omega_y & \omega_x & 0

\end{bmatrix}
=\dot{R}R^{-1}
```



即

```math
\omega_x = s_{32}, \quad \omega_y = s_{13}, \quad \omega_z = s_{21}
```

那么便有

```math
\omega =
\begin{bmatrix}
s_{32} \\
s_{13} \\
s_{21}
\end{bmatrix}
```

> 其中旋转矩阵同样是可以是：3×3的旋转矩阵如${}_6^0R$、四元数、绕轴以及给定的欧拉角来描述.

刚体在==平面==内绕固定 {Z}轴旋转，姿态矩阵为

```math
R = R_z(\theta) =
\begin{bmatrix}
\cos\theta & -\sin\theta & 0 \\
\sin\theta & \cos\theta & 0 \\
0 & 0 & 1
\end{bmatrix}
```

则$\dot{R_z(\theta)}$求导得

```math
\dot{R} =
\begin{bmatrix}
-\dot{\theta}\sin\theta & -\dot{\theta}\cos\theta & 0 \\
\dot{\theta}\cos\theta & -\dot{\theta}\sin\theta & 0 \\
0 & 0 & 0
\end{bmatrix}
```



那么就能得到叉乘矩阵

```math
[\omega]_\times = \dot{R}R^T=
\begin{bmatrix}
0 & -\dot{\theta} & 0 \\
\dot{\theta} & 0 & 0 \\
0 & 0 & 0
\end{bmatrix}=\begin{bmatrix}
0 & -\omega_z & \omega_y \\
\omega_z & 0 & -\omega_x \\
-\omega_y & \omega_x & 0
\end{bmatrix}
```

因此有

```math
\omega_x = 0, \quad \omega_y = 0, \quad \omega_z = \dot{\theta}
```



得到角速度

```math
\omega =
\begin{bmatrix}
0 \\
0 \\
\dot{\theta}
\end{bmatrix}
```

> 1. 这就是为什么平面运动中经常直接说：$\omega = \dot{\theta}$，因为平面旋转只有一个自由度.
>
> 2. 上式是一个通式，即对于绕轴转动角度的导数就是此轴转动下产生的角速度.

## 4.4.3 机器人连杆学

以上讨论了对于线速度和角速度的求解，现在讨论计算机器人连杆线速度和角速度的问题。

在机器人连杆运动的分析中，一般使用连杆坐标系 {0} 作为参考坐标系。因此，$v_i$ 是连杆坐标系原点{i}的线速度，$ω_i$ 是连杆坐标系{i}的角速度。

操作臂是一个链式结构，每一个连杆的运动都与它的相邻杆有关。由于这种结构的特点，我们可以**==由基坐标系==**依次计算各连杆的速度。连杆 {i+1}的速度就是连杆{i} 的速度加上那些附加到关节{i+1}上的新的速度分量。

如图 5-6 所示，将机构的每一个连杆看作为一个刚体，可以用线速度矢量和角速度矢量描述其运动。进一步，我们可以用连杆坐标系本身描述这些速度，而不用基坐标系。

图 5-7 所示为连杆 i 和 i+1，以及在连杆坐标系中定义的速度矢量。==**当两个 ω 矢量都是相对于同一个坐标系时**==，==**那么这些角速度能够相加**==。因此，连杆 i+1 的角速度就等于连杆 i 的角速度加上一个由于关节 i+1 的角速度引起的分量。参照坐标系 {i}，上述关系可写成

```math

\tag{5-43}
```

其中

```math

\dot{\theta}_{i+1}
\end{bmatrix}
```

<img src="./images/d6.png" alt="d6" style="zoom:67%;" />

```math
\tag{5-45}
```

坐标系 {i+1} **==原点的线速度==**等于坐标系 {i} 原点的线速度加上一个由于连杆 i 的角速度引起的新的分量。这与之前我们讨论线速度求解完全一致。我们本节仅讨论**==旋转关节==**，因此有

```math

```

上式两边同时左乘${}_i^{i+1}R$，得

```math

\tag{5-47}
```

矩阵表达如下

```math
\begin{bmatrix}

{}^B \omega_B
\end{bmatrix}
=
\begin{bmatrix}
{}^B_A R & -{}^B_A R {}^A P_{BORG} \times \\
0 & {}^B_A R
\end{bmatrix}
\begin{bmatrix}
{}^A v_A \\
{}^A \omega_A
\end{bmatrix}
```



> 1. 对于关节 i+1 为移动关节的情况，相应的关系为:
>
> ```math
> {}^{i+1}\omega_{i+1} = {}^{i+1}_iR {}^i\omega_i\\{}^{i+1} v_{i+1} = {}^{i+1}_i R \left( {}^i v_i + {}^i\omega_i \times {}^i P_{i+1} \right) + \dot{d}_{i+1} {}^{i+1}\hat{Z}_{i+1}
> ```
>
> 2. 我们发现$-{}^B_A R {}^A P_{BORG}$这里是有负号，原因就是叉乘不满足交换律，如a×b = -b ×a

从一个连杆到下一个连杆依次应用这些公式，可以计算出最后一个连杆的角速度${}^ Nω_N$ 和线速度 ${}^ Nv_N$，注意，这两个速度是按照坐标系 {N} 表达的。在后面可以看到，这个结果是非常有用的。如果用**==基坐标系来表达角速度和线速度==**的话，==就可以用 ${}^N_0R$ 去左乘速度，向基坐标进行旋转变换。==

## 4.4.4 速度雅可比

### 1. 定义

雅可比矩阵是多元形式的导数。例如设q为广义关节变量，$q={[q_1 \quad q_2 \quad q_3 \quad q_4 \quad q_5 \quad q_6 ]}^T$,则根据正运动学有

```math
\begin{align*}
x &= x(q_1, q_2, \dots, q_n) = x(\mathbf{q}) \\
y &= y(q_1, q_2, \dots, q_n) = y(\mathbf{q}) \\
z &= z(q_1, q_2, \dots, q_n) = z(\mathbf{q}) \\
\phi_x &= \phi_x(q_1, q_2, \dots, q_n) = \phi_x(\mathbf{q}) \\
\phi_y &= \phi_y(q_1, q_2, \dots, q_n) = \phi_y(\mathbf{q}) \\
\phi_z &= \phi_z(q_1, q_2, \dots, q_n) = \phi_z(\mathbf{q})
\end{align*}
```



也可以用矢量符号表示这些等式

```math
\mathbf{X} = \begin{bmatrix} x & y & z & \phi_x & \phi_y & \phi_z \end{bmatrix}^T = \mathbf{X}(\mathbf{q})
```

现在，如果想要计算出 $X_i$ 的微分关于 $q_j$ 的微分的函数，可简单应用多元函数求导法则计算，得到

```math
\begin{align*}
\delta x &= \frac{\partial x}{\partial q_1} \delta q_1 + \frac{\partial x}{\partial q_2} \delta q_2 + \cdots + \frac{\partial x}{\partial q_n} \delta q_n \\
\delta y &= \frac{\partial y}{\partial q_1} \delta q_1 + \frac{\partial y}{\partial q_2} \delta q_2 + \cdots + \frac{\partial y}{\partial q_n} \delta q_n \\
\delta z &= \frac{\partial z}{\partial q_1} \delta q_1 + \frac{\partial z}{\partial q_2} \delta q_2 + \cdots + \frac{\partial z}{\partial q_n} \delta q_n \\
\delta \phi_x &= \frac{\partial \phi_x}{\partial q_1} \delta q_1 + \frac{\partial \phi_x}{\partial q_2} \delta q_2 + \cdots + \frac{\partial \phi_x}{\partial q_n} \delta q_n \\
\delta \phi_y &= \frac{\partial \phi_y}{\partial q_1} \delta q_1 + \frac{\partial \phi_y}{\partial q_2} \delta q_2 + \cdots + \frac{\partial \phi_y}{\partial q_n} \delta q_n \\
\delta \phi_z &= \frac{\partial \phi_z}{\partial q_1} \delta q_1 + \frac{\partial \phi_z}{\partial q_2} \delta q_2 + \cdots + \frac{\partial \phi_z}{\partial q_n} \delta q_n
\end{align*}
```



矩阵形式表达如下

```math
\underbrace{
\begin{bmatrix}
\delta x \\
\delta y \\
\delta z \\
\delta \phi_x \\
\delta \phi_y \\
\delta \phi_z
\end{bmatrix}
}_{\delta \mathbf{X}}
=
\underbrace{
\begin{bmatrix}
\frac{\partial x}{\partial q_1} & \frac{\partial x}{\partial q_2} & \cdots & \frac{\partial x}{\partial q_n} \\
\frac{\partial y}{\partial q_1} & \frac{\partial y}{\partial q_2} & \cdots & \frac{\partial y}{\partial q_n} \\
\frac{\partial z}{\partial q_1} & \frac{\partial z}{\partial q_2} & \cdots & \frac{\partial z}{\partial q_n} \\
\frac{\partial \phi_x}{\partial q_1} & \frac{\partial \phi_x}{\partial q_2} & \cdots & \frac{\partial \phi_x}{\partial q_n} \\
\frac{\partial \phi_y}{\partial q_1} & \frac{\partial \phi_y}{\partial q_2} & \cdots & \frac{\partial \phi_y}{\partial q_n} \\
\frac{\partial \phi_z}{\partial q_1} & \frac{\partial \phi_z}{\partial q_2} & \cdots & \frac{\partial \phi_z}{\partial q_n}
\end{bmatrix}
}_{\mathbf{J}(\mathbf{q}) = \frac{\partial \mathbf{X}}{\partial \mathbf{q}}}
\underbrace{
\begin{bmatrix}
\delta q_1 \\
\delta q_2 \\
\vdots \\
\delta q_n
\end{bmatrix}
}_{\delta \mathbf{q}}
\tag{5-58}
```

将上述式子写成更为简单的矢量表达式

```math
\delta \mathbf{X} = \frac{\partial \mathbf{X}}{\partial \mathbf{q}} \delta \mathbf{q}
\tag{5-61}
```





式 (5-61) 中的 6×6 偏导数矩阵就是我们所说的雅可比矩阵 J，那么可以表达如下

```math
\delta \mathbf{X} =J(q) \delta \mathbf{q}
```

将上式两端同时除以时间的微分，可以将雅可比矩阵看成是 q即关节变量在关节空间 中的速度向X 即机器人末端在Cartesian空间中速度的映射.

```math
\dot{\mathbf{X}} = \mathbf{J}(\mathbf{X}) \dot{\mathbf{q}}
```

在任一瞬时，q都有一个确定的值，J(X) 是个线性变换。在每一个新时刻，如果 q 改变，线性变换也会随之而变。所以，雅可比是**==时变的线性变换==**。

在机器人学中，通常使用雅可比将关节速度与操作臂末端的笛卡儿速度联系起来，比如：

```math
{}^0 \mathbf{v} = {}^0 \mathbf{J}({\Theta}) \dot{{\Theta}}\tag{5-64}
```

式中，Θ 是操作臂关节角矢量，v 是笛卡儿速度矢量。在式 (5-64) 中，我们给雅可比表达式附加了**==左上标==**，以此表示==笛卡儿速度所参考的坐标系==。有时，由于参考坐标系很明显而不用说明，或者对后续推导并不重要时，这个左上标就可以略去。注意到，对于任意已知的操作臂位形，==**关节速度**和**操作臂末端速度**==的关系是**==线性==**的，然而这种线性关系仅是**==瞬时==**的，因为在**==下一刻==**，雅可比矩阵就会有**==微小的变化==**。对于通常的 6 关节机器人，雅可比矩阵是 6×6 阶的矩阵，$\dot{\theta}$ 是 6×1 维的，${}^0 v$ 也是 6×1 维的。这个 6×1 笛卡儿速度矢量是由一个 3×1 的线速度矢量和一个 3×1 的角速度矢量组合起来的：

```math
{}^0 \mathbf{v} = \begin{bmatrix} {}^0 v \\ {}^0 \omega \end{bmatrix}=
\begin{bmatrix}
v_x \\
v_y \\
v_z \\
\omega_x \\
\omega_y \\
\omega_z
\end{bmatrix}
```

可以定义任何维数的雅可比矩阵（包括非方阵形式）。雅可比矩阵的行数等于操作臂在笛卡儿空间的自由度数量，雅可比矩阵的列数等于操作臂的关节数量。例如，对于平面操作臂，虽然雅可比矩阵不可能超过 3 行，但对于冗余度平面操作臂，可以有任意多个列（列数和关节数相等）。

对于两连杆的操作臂，可以写出一个 2×2 的雅可比矩阵，该矩阵将关节速度和末端执行器的速度联系起来。利用例 5.3 的结果，可以很容易地给出两连杆操作臂的雅可比矩阵。可以由式 (5-55) 写出坐标系 {3} 中的雅可比表达式：

```math
{}^3 \mathbf{J}({\Theta}) =
\begin{bmatrix}
l_1 s_2 & 0 \\
l_1 c_2 + l_2 & l_2
\end{bmatrix}
```

由式 (5-57) 可以写出坐标系 {0} 中的雅可比表达式：

```math
{}^0 \mathbf{J}({\Theta}) =
\begin{bmatrix}
-l_1 s_1 - l_2 s_{12} & -l_2 s_{12} \\
l_1 c_1 + l_2 c_{12} & l_2 c_{12}
\end{bmatrix}
```

注意，在上述两种情况下，都选择了一个方阵将关节速度和末端执行器的速度联系起来。当然，也可以选择包含末端执行器角速度的 3×2 阶雅可比矩阵。

通过从式 (5-58) 到式 (5-61) 建立雅可比矩阵的过程，我们会发现，也可以通过**==对机构的运动方程直接微分来求得雅可比矩阵==**。**==这样可以直接求得线速度，但却得不到 3×1 的方位矢量==**，而这个矢量的导数就是 ω。我们已经介绍了一种方法，就是通过依次使用式 (5-45) 和式 (5-47) 求出雅可比矩阵。也可以应用另外的几种方法来求例如矢量积法和微分变换法等.



并且我们观察式5-58的雅可比矩阵可以发现如下含义

1. 每一列表示其他关节不动而某一关节运动的端点速度对末端速度的贡献量；

2. 前三行代表末端线速度与关节速度传递比；后三行代表末端角速度与关节速度传递比。

3. 雅可比矩阵J(q)是函数的一阶偏导数以一定方式排列成的矩阵，不仅可以用来表示操作空间速度与关节空间速度之间的线性映射关系，同时也用来表示两空间之间力的传递关系。



### 2. 雅可比参考坐标系变换

已知坐标系{B}中的雅可比矩阵，即

```math
\begin{bmatrix}
{}^B \mathbf{v} \\
{}^B {\omega}
\end{bmatrix}
= {}^B \mathbf{v} = {}^B J({\Theta}) \dot{{\Theta}}
\tag{5-68}
```

我们关心的是给出雅可比矩阵在另一个坐标系{A}中的表达式。首先，注意到已知坐标系{B}中的6×1笛卡儿速度矢量可以通过如下变换得到相对于坐标系{A}的表达式

```math
\begin{bmatrix}
{}^A \mathbf{v} \\
{}^A {\omega}
\end{bmatrix}
=
\begin{bmatrix}
{}^A_B R & 0 \\
0 & {}^A_B R
\end{bmatrix}
\begin{bmatrix}
{}^B \mathbf{v} \\
{}^B {\omega}
\end{bmatrix}
\tag{5-69}
```

因此，可以得到

```math
\begin{bmatrix}
{}^A \mathbf{v} \\
{}^A {\omega}
\end{bmatrix}
=
\begin{bmatrix}
{}^A_B R & 0 \\
0 & {}^A_B R
\end{bmatrix}
{}^B J({\Theta}) \dot{{\Theta}}
\tag{5-70}
```

显然，利用下列关系式可以完成雅可比矩阵参考坐标系的变换：

```math
{}^A J({\Theta}) =
\begin{bmatrix}
{}^A_B R & 0 \\
0 & {}^A_B R
\end{bmatrix}
{}^B J({\Theta})
\tag{5-71}
```



> 关节变量 $\Theta$和关节速度 $\dot\Theta$不属于某个笛卡尔坐标系，它们是机械臂自身的广义坐标。
>

### 3. 矢量积法表达

根据矢量力学原理，可通过矢量积法求解**==机器人末端==**相对于**==基坐标系{0}==**的雅可比矩阵。

假设机器人末端相对于基坐标系的线速度和角速度分别为 v 和 ω，则末端线速度和角速度可看作**==各关节线速度和角速度的叠加==**，具体来说，每个关节对应于雅可比矩阵的一列，可按关节类型逐列求解雅可比矩阵。

若关节 j 为转动关节，则该关节转动时，将在末端同时产生转动和移动。关节 j 的转动在末端产生的角速度为

```math
\boldsymbol{\omega}_j = \boldsymbol{Z}_j \dot{q}_j

```

> 其中$Z_i$表示把当前关节轴方向放到基坐标系观察，对于叠加只能在同一坐标系才能进行，如下也验证之前在4.4.2中3小节所讲解的推导
>
> ```math
> {}^0 Z_j = {}^0_j R
> \begin{bmatrix}
> 0 \\
> 0 \\
> 1
> \end{bmatrix}
> ```
>
> 

关节 j 的转动在末端产生的线速度为

```math
\boldsymbol{v}_j = (\boldsymbol{Z}_j \times {}^0\boldsymbol{P}_j^n) \dot{q}_j
```

> Tips
>
> 1. 这里计算的是偏导即除了j关节以外其他关节一律不懂因此只有转动的速度，其实本质和在4.4.3学习的一样，因为这里最终是将所有的单独贡献于末端线速度叠加，最终效果一致.
> 2. 推导如下
>
> ```math
> \begin{align*}
> v &= \omega \times r. \\
> \omega_j &= Z_j \dot{q}_j, \\
> r &= {}^0 P_j^n. \\
> v_j &= \omega_j \times {}^0 P_j^n. \\
> v_j &= (Z_j \dot{q}_j) \times {}^0 P_j^n. \\
> v_j &= (Z_j \times {}^0 P_j^n) \dot{q}_j
> \end{align*}
> ```
>
> 

式中,${}^0P_j ^n$ 为由坐标系 {j} 的原点到末端坐标系 {n} 的原点的矢量在 {0} 坐标系下的坐标，有

```math
{}^0\boldsymbol{P}_j^n = {}_j^0 R \boldsymbol{P}_j^n
```

> ```math
> {
> {}^0 P_j^n
> = {}^0_j R {}^j P_{j+1}
> + {}^0_{j+1} R {}^{j+1} P_{j+2}
> + \cdots
> + {}^0_{n-1} R {}^{n-1} P_n
> }
> ```
>
> 在向量中理解
>
> ```math
> {}^0 P_j^n = {}^0 p_n - {}^0 p_j
> ```
>
> 

则雅可比矩阵的第 j 列为

```math
\boldsymbol{J}_j =
\begin{bmatrix}
\boldsymbol{Z}_j \times {}^0\boldsymbol{P}_j^n \\
\boldsymbol{Z}_j
\end{bmatrix}
=
\begin{bmatrix}
\boldsymbol{Z}_j \times ({}_j^0 R \boldsymbol{P}_j^n) \\
\boldsymbol{Z}_j
\end{bmatrix}
```

> 需要注意的是，矢量积法求得的雅可比矩阵是相对于基坐标系的，机器人末端的线速度和角速度也都是相对于基坐标系的。



## 4.4.5 奇异性



已知一个线性变换可以将关节速度和笛卡儿速度联系起来，那么自然会提出一个问题：这个线性变换矩阵是可逆的吗？也就是说，这个矩阵是非奇异的吗？如果这个矩阵是非奇异的，那么已知笛卡儿速度的话，就可以对该矩阵求逆计算出关节的速度

```math
\dot{\Theta} = J^{-1}(\Theta) v\tag{5-72}
```

这是一个重要的关系式。例如，要求机器人手部在笛卡儿空间以某个速度矢量运动。应用式 (5-72)，可以计算出沿着这个路径每一瞬时所需的关节速度。这样，雅可比矩阵可逆性的实质问题就在于：雅可比矩阵对于所有的Θ值都是可逆的吗？如果不是，在什么位置不可逆？

大多数操作臂都有使得雅可比矩阵出现奇异的Θ值，对于方阵雅可比就是行列式伪 0，对于非方阵就是“秩亏”即rank(J)<min{m,n}以及这些位置就称为机构的**==奇异位形==**或简称奇异状态。==**所有操作臂在工作空间的边界都存在奇异位形**==，并且大多数操作臂在它们的工**==作空间内也有奇异位形==**,奇异位形大致将它们分为两类：

1. 工作空间边界的奇异位形出现在操作臂完全展开或者收回使得末端执行器处于或非常接近工作空间边界的情况，也称为肘部奇异性或边界奇异性.
2. 工作空间内部的奇异位形出现在远离工作空间的边界，通常是由于两个或两个以上的关节轴线共线引起的，通常有腕部奇异性和肩部奇异行，对于一般六自由度机械臂时长发生腕部奇异性

![d10](./images/d10.png)

> 不论雅可比是否时方阵，对于是否奇异就是rank(J)<min{m,n}若成立则处于奇异.

当一个操作臂处于奇异位形时，它会失去一个或多个自由度（在笛卡儿空间中观察）。这也就是说，在笛卡儿空间的某个方向上（或某个子空间中），无论选择什么样的关节速度，都不能使机器人手臂运动。显然，这种情况也会在机器人的工作空间边界发生。

在机器人控制系统中应用式 (5-72) 的危险在于，在奇异位形，雅可比矩阵的逆不存在即不可逆或者不满秩，根据线性代数知识可知等价于行列式为0,那么雅可比矩阵不可逆

```math
{\left| J(q) \right|=0}
```

当操作臂接近奇异点位置时，即Det(J)趋近于0即雅可比的逆矩阵无穷大，计算时无论执行器的速度如何，最终的关节速度会无穷大.

```math
\dot{\Theta} =  J^{-1}(\Theta) v=\frac{J^*(\Theta)}{\left| J(\Theta) \right|} v \to \infty
```



## 4.4.6 雅可比伪逆求解

由4.4.4和4.4.5小节我们了解了速度雅可比和当雅可比矩阵行列式为0会出现奇异状态，若机械臂为非冗余六自由度机械臂，并且雅可比矩阵为满秩方阵，则可以直接求逆：

```math
\dot{q} = J^{-1}(q) V
```

但是在实际机械臂中，常常会遇到以下情况雅可比矩阵不是方阵、机械臂存在冗余自由度、机械臂接近奇异位形这样数值计算中 $J^{-1}$ 不稳定，也就是当雅可比矩阵不是方阵或者雅可比矩阵式方阵但是不可逆，这时候一般使用雅可比伪逆（Moore-Penrose ，广义逆）求解关节速度：

```math
\dot{q} = J^+(q) V
```

> 1. 当 $J\in\mathbb R^{m\times n}$ 且满列秩时
>
> ```math
> J^+ = (J^T J)^{-1} J^T
> ```
>
> 2. 当 $J\in\mathbb R^{m\times n}$ 且满行秩时
>
> ```math
> J^+ = J^T (J J^T)^{-1}
> ```
>
> 



对于机械臂速度控制，常见的是任务维度小于或等于关节维度，因此常用

```math
\dot{q} = J^T (J J^T )^{-1} V
```

### 1. 冗余机械臂伪逆求解

当机械臂自由度数量大于任务空间维度时，称为冗余机械臂。例如，7 自由度机械臂执行 6 维末端位姿任务时，关节自由度多于任务约束，这时未知数比方程多，解不唯一，伪逆给出其中一组常用解：

```math
J \dot{q} = V_d

```

此时伪逆解：

```math
{\dot{q} = J^+ V_d}
```

```math
J^+ V_d = \arg\min_{\dot{q}} \left\| \dot{q} \right\| \quad \text{s.t.} \quad J \dot{q} = V_d
```



> 给出的是最小范数解，即在所有满足末端速度要求的关节速度中，选择关节整体运动最小的一组，这可以使机械臂运动更加平滑，避免不必要的关节快速运动。





### 2. 零空间运动

当机械臂具有冗余自由度时，可以在不影响末端运动的情况下调整关节姿态，有如下通式

```math
\dot{q} = J^+ V + (I - J^+ J) z
```

其中：

- $J^+V$：实现末端任务的主任务速度；
- $I-J^+J$：零空间投影矩阵；
- z：任意关节速度向量。

由于

```math
J(I - J^+ J) z = 0
```

所以零空间项不会改变末端速度，因此，零空间运动可以在不影响末端轨迹跟踪的情况下实现副任务，例如避障、远离关节限位、优化姿态或远离奇异位形。



> 说明
>
> ​		对于普通六自由度机械臂执行完整位姿抓取任务时，若雅可比矩阵满秩，则关节速度由末端速度唯一确定，通常不存在可利用的零空间运动。零空间方法主要适用于冗余机械臂，或任务维度低于机械臂自由度的情况。对于本文左机械臂若仅执行完整六维抓取位姿跟踪，则零空间运动可作为扩展内容简要介绍；若后续考虑只约束位置或部分姿态，则零空间可用于避障、关节限位规避和远离奇异位形。

### 3. SVD奇异值分解和伪逆求解

当雅可比矩阵秩下降时，即rank(J)<{m,n}时，机械臂会进入奇异位形。此时末端在某些方向上的运动能力会减弱甚至丧失，为了分析奇异性，可以对雅可比矩阵进行奇异值分解

```math
{J = U\Sigma V^T}
```



- 其中 $\Sigma$ 的对角线元素为奇异值：

```math
\sigma_1, \sigma_2, \dots, \sigma_r.
```

```math
\sigma_i^+ = 
\begin{cases} 
\frac{1}{\sigma_i}, & \sigma_i > 0, \\ 
0, & \sigma_i = 0. 
\end{cases}
```

> 可以将每个奇异值理解为某个方向上的“运动传递比例”：末端速度分量 = $\sigma_i \times$ 关节速度分量

- U：末端任务空间中的方向

- V：关节空间中的方向；

当最小奇异值满足：$\sigma_{\min} \approx 0$时，说明机械臂接近奇异位形，此时此法解出的伪逆无穷大，为了避免这种解，我们采用阻尼最小二乘法来缓解，接下来我们会讲到.

当最小奇异值满足：$\sigma_{\min} = 0$时，说明机械臂处于奇异位形，这时的解不是无穷大，SVD 会将严格为零的奇异值对应的倒数设置为零，数学定义上的伪逆通常仍为有限值，最终机械臂已经失去某些末端运动方向，期望速度可能无法准确实现



由 SVD 可得伪逆：

```math
J^+ = V\Sigma^+ U^T.
```

其中：

```math
\Sigma^+ = \mathrm{diag}\left(\frac{1}{\sigma_1}, \frac{1}{\sigma_2}, \dots\right).
```

因此当某个奇异值接近零时，伪逆中会出现很大的数值，导致关节速度异常增大。这就是奇异附近伪逆求解不稳定的原因。

> 与公式定义求解说明：
>
> 1. 公式条件时在$JJ^T$可逆情况也就是J是非奇异时，可利用公式求解
> 2. 对于J奇异，此时无法使用公式求解，引入SVD以用于计算当雅可比矩阵奇异时的 Moore-Penrose 伪逆，同时可以通过奇异值判断雅可比矩阵是否接近奇异

### 4. 可操作度与奇异性判断

除了最小奇异值，也可以使用可操作度衡量机械臂当前位形的运动能力

```math
{w(q) = \sqrt{\det\left(J J^T\right)}}
```

当 $w(q)$ 较大时，说明机械臂在各方向上的运动能力较好；当$w(q) \to 0$时，说明机械臂接近奇异位形。

因此，在轨迹规划过程中，可以通过监测$\sigma_{\min}$ 或$w(q)$判断机械臂是否接近奇异区域.

### 3. 奇异问题——阻尼最小二乘法(DLS)

当雅可比矩阵秩下降时，机械臂会进入奇异位形，在数学表示为

```math
rank(J)<m
```

若J为方阵这时雅可比的行列为0，接近奇异位形，直接求逆导致关节速度无穷大.

为了避免奇异点附近关节速度过大，常使用阻尼最小二乘法：

```math
\dot{q}(t) = J^T (J J^T + \lambda^2 I)^{-1} V
```

其中：

- $\lambda>0$：阻尼因子；
- I：单位矩阵。

当远离奇异点时，$\lambda$可以较小，此时结果接近普通伪逆，当接近奇异点时，$\lambda$增大，可以抑制关节速度发散，阻尼最小二乘法牺牲了一部分末端速度跟踪精度，换取数值稳定性，对于轨迹规划和抓取任务，它通常比直接求逆更安全。

阻尼最小二乘法相当于把普通伪逆中的：

```math
\frac{1}{\sigma_i}
```

改成：

```math
{\frac{\sigma_i}{\sigma_i^2 + \lambda^2}}
```

这样当$\sigma_i \to 0$时，不会发散。

> 所以它主要解决接近奇异时关节速度过大、不稳定的问题，而不是恢复已经丢失的自由度。

### 4. 奇异问题——基于可操作空间的零度优化

若希望机械臂主动远离奇异位形，可以将可操作度作为零空间优化目标：

```math
{\dot{q} = J^+ V_d + \left(I - J^+ J\right) k \nabla w(q)}
```

其中：

- $J^+V_d$：完成末端轨迹跟踪；
- $(I-J^+J)$：零空间投影；
- $\nabla w(q)$：可操作度关于关节变量的梯度；
- $k$：调节系数。

该方法可以在不影响末端主任务的前提下，使机械臂朝可操作度更高的位形运动，从而降低接近奇异位形的风险。



### 5. 总结

|        情况        |        求解目标        |   常用解法   |      结果特点      |
| :----------------: | :--------------------: | :----------: | :----------------: |
|      方阵满秩      |        精确求解        | $J^{-1}V_d$  |     唯一精确解     |
|    冗余且满行秩    |  精确解中关节速度最小  |   $J^+V_d$   |   最小范数精确解   |
| 自由度不足且满列秩 |    末端速度误差最小    |   $J^+V_d$   |     最小二乘解     |
|   秩亏/严格奇异    | 最小误差，再选最小范数 |   SVD 伪逆   |  无法实现丢失方向  |
|      接近奇异      | 平衡跟踪误差和关节速度 | 阻尼最小二乘 | 稳定但存在跟踪误差 |



## 4.4.7 力雅可比



由于本文主要关注机械臂末端轨迹规划与抓取过程中的运动控制，暂不涉及接触力控制与力矩分配问题，因此力雅可比仅作概念性说明。后续若进一步研究抓取稳定性、接触力控制或阻抗控制，则需要利用下式建立末端力与关节力矩之间的映射关系

```math
\tau = J^TF
```
