5. 添加自己定义的文件。

   @1->msgs

在 ROS 通信协议中，数据载体是一个较为重要组成部分，ROS 中通过 std_msgs 封装了一些原生的数据类型,比如:String、Int32、Int64、Char、Bool、Empty.... 但是，这些数据一般只包含一个 data 字段，结构的单一意味着功能上的局限性，当传输一些复杂的数据，比如: 激光雷达的信息... std_msgs 由于描述性较差而显得力不从心，这种场景下可以使用自定义的消息类型

msgs只是简单的文本文件，每行具有字段类型和字段名称，可以使用的字段类型有：

- int8, int16, int32, int64 (或者无符号类型: uint*)
- float32, float64
- string
- time, duration
- other msg files
- variable-length array[] and fixed-length array[C]

​	**CMakeLists.txt**编辑 msg 相关配置

```cpp
find_package(catkin REQUIRED COMPONENTS
  roscpp
  rospy    #提示：刚才添加的rospy
  std_msgs
  message_generation
)
# 需要加入 message_generation,必须有 std_msgs




## 配置 msg 源文件  -----  原本是注释，需要打开，并作相应更改
add_message_files(
  FILES
  Person.msg
)


# 生成消息时依赖于 std_msgs ------ 原本是注释，需要打开，并作相应更改
generate_messages(
  DEPENDENCIES
  std_msgs
)



#执行时依赖    -------原本是注释，需要打开，并作相应更改
catkin_package(
#  INCLUDE_DIRS include
#  LIBRARIES demo02_talker_listener
  CATKIN_DEPENDS roscpp rospy std_msgs message_runtime   #如果之前床玩包才添加rospy，按之前的配置并没有此步，一旦涉及到自定义类的话就要在这里也加上自己新添加的依赖，eg   :  rospy。
#  DEPENDS system_lib
)
```

​	@2->service

1. 功能包下新建 srv 目录，添加 AndInts.srv 文件，内容

   ```cpp
   # 客户端请求时发送的两个数字
   int32 num1
   int32 num2
   ---
   # 服务器响应发送的数据
   int32 sum
   ```

   

2. **package.xml**中添加编译依赖与执行依赖

   ```cpp
     <build_depend>message_generation</build_depend>
     <exec_depend>message_runtime</exec_depend>
   ```

   

3. **CMakeLists.txt**编辑 srv 相关配置

   ```cpp
   find_package(catkin REQUIRED COMPONENTS
     roscpp
     rospy
     std_msgs
     message_generation
   )
   # 需要加入 message_generation,必须有 std_msgs
   
   
   
   add_service_files(
     FILES
     AddInts.srv
   )
   
   
   generate_messages(
     DEPENDENCIES
     std_msgs
   )
   ```
